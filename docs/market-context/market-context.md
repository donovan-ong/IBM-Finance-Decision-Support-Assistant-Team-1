**Scenario:** Mid-sized clothing retailer, Melbourne, Victoria

**Data:** All indicator values are sourced from named external data providers — the Australian Bureau of Statistics (ABS), the Reserve Bank of Australia (RBA), the World Bank, and the Essential Services Commission (ESC) Victoria — via the raw files listed in Section 3. Nothing is invented, estimated, or generated by the team or the Assistant; every value is traceable to a specific file, sheet, and column (see the companion data-sources reference document).

---

## 1. Purpose

Defines how the Assistant adds market context when explaining a financial variance — which categories get it, what indicators are used, and how it must be worded and cited. Used only in the Explain step of the workflow:

**Detect → Calculate → Classify → Explain → Present → Human Decision**

---

## 2. Categories and priority

| Category | Category_Group | Market context priority |
|---|---|---|
| Revenue | Revenue | High |
| Cost of Goods Sold | COGS | High |
| Utilities Expense | Expense | Medium |
| Payroll Expense | Expense | Low |
| Marketing Expense | Expense | Low |
| Rent Expense | Expense | Low |
| Other Expense | Expense | Low |

- **High / Medium:** the Assistant checks for market context whenever a variance is flagged.
- **Low:** the Assistant does not check by default. It only does so if a separate qualitative flag says the variance looks unusual for other reasons.

Priority only controls whether the Assistant looks for market context. It has no effect on which indicator a category uses — that mapping is the same regardless of priority (Section 3).

## 3. Indicator mapping

Each category maps directly to its own indicator(s) and the external file that indicator is sourced from:

| Category | Indicator(s) | Source |
|---|---|---|
| Revenue | Consumer clothing & footwear spending; AUD/USD exchange rate | **ABS Monthly Household Spending Indicator** — 5682002.xlsx, Sheet: Data1, Column 25 (Clothing and footwear, Original, % change from a year ago); **RBA Table F11.1** — 2023-current.xls, Sheet: Data, Column B (A$1=USD) |
| Cost of Goods Sold | Cotton price index; AUD/USD exchange rate | **World Bank Commodity Price Data (Pink Sheet)** — CMO-Historical-Data-Monthly.xlsx, Sheet: Monthly Prices, Column: Cotton, A Index; **RBA Table F11.1** — 2023-current.xls, Sheet: Data, Column B (A$1=USD) |
| Utilities Expense | Electricity price (small business) | **Essential Services Commission (ESC) Victoria** — Victorian Default Offer (VDO), small business figures, from the official annual Final Decision Papers. One figure per financial year (1 Jul–30 Jun): 2024–25 = $3,530; 2025–26 = $3,620; 2026–27 = $3,380 |
| Payroll Expense | Inflation rate; Interest rate | **ABS Consumer Price Index Australia** — ABS_Consumer_Price_Index_Australia.xlsx, Sheet: Data1, Column K (% change from the same month last year); **RBA Table F1.1** — f01hist.xlsx, Sheet: Data, Column B (Cash Rate Target) |
| Marketing Expense | Inflation rate; Interest rate | Same two sources as Payroll Expense, above |
| Rent Expense | Inflation rate; Interest rate | Same two sources as Payroll Expense, above |
| Other Expense | Inflation rate; Interest rate | Same two sources as Payroll Expense, above |

**Rule:** where a category lists more than one indicator, cite all of them — never pick just one.

## 4. Stored indicator record

Each indicator is stored as one row with these fields:

| Field | Example |
|---|---|
| Category | Rent Expense |
| Indicator | Inflation rate |
| Period | 2026-06 |
| Value | 3.8 |
| Unit | % |
| Source | ABS Consumer Price Index Australia |

Lookup always uses Category + Indicator + Period together — Category alone can match more than one row. If no row matches the period, the Assistant says so; it never substitutes a different period's value.

**Note on quarterly/annual queries:** The stored table is monthly. When a query requests a quarter or year (e.g. "Q2 2026"), the Assistant retrieves all matching months individually (e.g. April, May, June 2026) and presents each month's value separately — it does not average them, since averaging can mask a single month's real spike or drop.

**Example:** " COGS deviated from the budget by X% in Q2 2026. During the same period, the cotton price moved as follows: April $1.90, May $2.03, and June $1.90 (Source: World Bank)."


---

## 5. Wording rules

- Language is always probabilistic — "may have contributed," "could be associated with" — never a confirmed cause.
- Every statement names the indicator, its value, the period, and its source.
- Template: "The [X%] variance in [Category] may be partly consistent with the [Y%] change in [Indicator] observed during [Period] (Source: [Source])."
- Two qualifying indicators → two separate sentences, not one merged sentence.
- No matching data for the period → "No matching market context is available for this period."
